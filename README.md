## Опис роботи

У межах лабораторної роботи реалізовано три рекурсивні функції для обходу ієрархічного дерева категорій (`Category`) та досліджено базовий випадок, зменшення задачі й кількість рекурсивних викликів (`callCount`):
1. **`printTree(node, level)`** — рекурсивно виводить усю ієрархію каталогу в консоль із відступом у два пробіли на кожен рівень вкладеності.
2. **`countProducts(node)`** — рекурсивно обчислює загальну кількість товарів у заданій категорії та всіх її вкладених підкатегоріях.
3. **`maxDepth(node)`** — рекурсивно визначає глибину найдовшої гілки дерева (де кореневий вузол має глибину `1`).

## Як запустити проєкт

1. Переконайтеся, що на комп'ютері встановлено **Python 3**:
   ```bash
   python --version
   ```

2. Перейдіть у папку лабораторної роботи `lab06`:
   ```bash
   cd lab06
   ```

3. Запустіть скрипт у терміналі:
   ```bash
   python lab06.py
   ```
   *(На Linux або macOS може знадобитися команда `python3 lab06.py`)*
